
# Dự Án Mini game platform  1

Đây là một dự án sử dụng html, CSS và javascript với giao diện người dùng chất lượng cao và ưu tiên trải nghiệm người dung. Để giúp tăng trải nghiệm người dùng chúng tôi đã sử dụng đồ hòa plasma form

## 🚀 Chức năng chính

* Là platform cho người dùng chọn game yêu thích.
* Hiện tại bản đới 1.0 mới có game block blast nhưng đội ngũ của chúng tôi sẽ có gắng làm nhanh nhất để phục vụ người dùng những con game chất lượng.
